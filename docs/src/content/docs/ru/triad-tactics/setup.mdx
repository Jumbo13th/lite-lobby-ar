Переходите к этому разделу, когда миссия уже готова. Здесь настроим её для сервера Triad Tactics. Также ознакомьтесь с [требованиями к миссиям](../requirements/): они определяют, в том числе, сколько очков назначать за задачи.

## 1. Подключение Triad Tactics Core {#core-dependency}

Добавьте **[Triad Tactics Core](https://reforger.armaplatform.com/workshop/69FF2C2B633BBC25)** в зависимости проекта: в **Project Settings → Dependencies** должна появиться строка **Triad Tactics Core** с идентификатором `69FF2C2B633BBC25`. Это обязательная зависимость для миссий сервера.

Скачайте аддон в Workshop и подключите его [так же, как Lite Lobby](../../create-mission/project/#lite-lobby-dependency). Правила использования других геймплейных модов приведены в [требованиях к миссиям](../requirements/#gameplay-mods).

## 2. Очки на триггере {#trigger-points}

В **World Editor** выберите триггер захвата — в нашем примере это `PortCapture`. В панели **Object Properties** откройте компонент **LL_TriggerZoneCapture** и задайте:

- **Stat Points** — общее количество очков за зону.
- **Stat Max Per Player** — лимит очков на одного участника, который учитывается при распределении очков между отрядами.

На скриншоте указаны `20` и `1`. Значения для своей миссии согласуйте с администрацией, как указано в [требованиях к очкам](../requirements/#points).

## 3. Зона статистики {#stat-zone}

Выберите объект, который задаёт границы зоны захвата, — в нашем примере это `PortTrigger`. Через **Add Component** добавьте к нему **LL_StatZoneComponent**.

Компонент отмечает область, в которой за убийство противника начисляются повышенные очки. Учитывается положение погибшего: он должен находиться внутри зоны. Множитель очков задаётся на сервере.

## 4. Сохранение сессии {#session-saves}

Сервер регулярно сохраняет игру. Если сервер упадёт, игра продолжится с последнего сохранения.

Triad Tactics Core сам отмечает **Session Saves** в игровом режиме. Чтобы проверить, выберите `LL_GameMode_Lobby1` в **Hierarchy** и введите `sess` в поле поиска свойств в **Object Properties**.

<LL_Screenshot
  src={sessionSaves}
  alt="Выбран LL_GameMode_Lobby1; поиск свойств по sess показывает отмеченный флажок Session Saves в разделе Lite Lobby."
  caption="Session Saves в игровом режиме."
  originalLabel="Открыть оригинал изображения"
/>

Миссии остаётся только разрешить сохранение. В **Resource Browser** откройте `Missions/ShootingStar_Ep1.conf`.

В разделе **Save Types** снова отметьте все четыре флажка: **MANUAL**, **AUTO**, **SCRIPTED** и **SHUTDOWN**. Если они сняты, как на [шаге с названием и описанием миссии](../../create-mission/world/#mission-details), игра ничего не сохраняет.

<LL_Screenshot
  src={saveTypes}
  alt="Файл ShootingStar_Ep1.conf: отмечены все четыре флажка Save Types — MANUAL, AUTO, SCRIPTED и SHUTDOWN."
  caption="Все четыре типа сохранений отмечены."
  originalLabel="Открыть оригинал изображения"
/>

Нажмите `..` рядом с **Systems Config**, откройте **LiteLobby → Configs → Systems** и выберите `LL_LobbySystems.conf`.

<LL_Screenshot
  src={systemsConfig}
  alt="Окно Choose SystemsConfig с выбранным LiteLobby/Configs/Systems/LL_LobbySystems.conf; в поле Systems Config указан LL_LobbySystems.conf."
  caption="Системный конфиг лобби."
  originalLabel="Открыть оригинал изображения"
/>

Нажмите `Ctrl+S`, чтобы сохранить файл сценария.

После падения сервера игра находит каждую группу по имени объекта. Дайте каждой группе со слотами [собственное имя](../../create-mission/groups-and-slots/#group-callsigns), например `AB_S1`; у двух групп не может быть одинакового имени.
