## Сохранение изменений {#save-commit-push}

Git позволяет хранить историю изменений проекта и возвращаться к сохранённым версиям. Для работы с ним будем использовать приложение [GitHub Desktop](https://desktop.github.com/).

Сохранение в редакторе, создание коммита и отправка на GitHub — три отдельных действия:

- **Save** в Workbench сохраняет текущие изменения в файлах миссии.
- **Commit** в GitHub Desktop сохраняет выбранные изменения в истории проекта. Такая запись называется коммитом; она хранится на вашем компьютере.
- **Push origin** отправляет созданные коммиты в репозиторий на GitHub.

Сохраните файлы в Workbench, затем проверьте список изменений в GitHub Desktop и создайте коммит. Так вы сможете вернуться к этой версии, если последующие правки приведут к ошибке или вы случайно удалите нужный файл. Отправьте коммит на GitHub, чтобы сохранить копию проекта вне своего компьютера.

[Официальная инструкция по началу работы с GitHub Desktop](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop).

Рекомендуемая структура папок показана в разделе [«Папка проекта»](../create-mission/project/#project-folder) основного руководства.
