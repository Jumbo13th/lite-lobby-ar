[К оглавлению руководства](../)

Персонажи готовы. Объединим их в группу, проверим её в Game Master, затем разместим в мире миссии и настроим игровые слоты. После этого добавим технику и стартовые зоны.

## Префаб группы {#group-prefab}

Префаб группы объединяет несколько префабов персонажей и позволяет разместить весь её состав сразу. В примере создадим **Split Team Alpha** — первую половину отряда ODA из миссии **Triad Shooting Star**. Для своего подразделения используйте свои названия и состав.

### Создание префаба {#create-group-prefab}

Остановите тестовый запуск игры и вернитесь в **World Editor**.

В проекте **ArmaReforger** откройте папку `Prefabs/Groups/BLUFOR`. Щёлкните правой кнопкой мыши по `Group_US_Base.et` и выберите **Inherit in → ваш аддон**.

  originalLabel="Открыть оригинал изображения"
/>

Введите имя `TSS_Group_US_GB_SplitTeamAlpha` и нажмите **OK**.

<LL_Screenshot

  caption="Название префаба группы."

В своём аддоне откройте папку `Prefabs/Groups/BLUFOR`. Щёлкните правой кнопкой мыши по свободному месту в **Resource Browser**, создайте папку `Green Berets` и перетащите в неё новый префаб.

### Название группы {#group-name}

Откройте `Language/tss_localization.st` в **String Editor**. [Добавьте строку](/lite-lobby-ar/ru/create-mission/character-editor/#localization-entry) с ключом `TSS-Groups_SplitTeamAlpha`:

- **Target En Us** — `Split Team Alpha`.
- **Target Ru Ru** — `Группа «Альфа»`.

Сохраните таблицу нажатием `Ctrl+S`, затем нажмите `Ctrl+B`, чтобы обновить файлы переводов для игры.

<LL_Screenshot
  src={groupTranslation}
  alt="В String Editor добавлена строка TSS-Groups_SplitTeamAlpha с английским названием Split Team Alpha."
  caption="Название группы в таблице переводов."
  originalLabel="Открыть оригинал изображения"
/>

Откройте `TSS_Group_US_GB_SplitTeamAlpha.et` через **Edit Prefab** и выберите объект группы. В поиске компонентов введите `edita`, выберите **SCR_EditableGroupComponent** и раскройте **Visualization → UI Info**.

В поле **Name** укажите `#TSS-Groups_SplitTeamAlpha`. В списке **Authored Labels** нажмите `+` и добавьте метку `GROUPSIZE_LARGE`, как в примере. Эта метка задаёт категорию размера группы в игровом редакторе.

### Условный знак {#group-symbol}

Ниже включите параметр **Use UI Info Name**, чтобы для группы использовалось название из поля **Name**. Затем в разделе **Military Symbol** задайте параметры условного знака:

- **Identity** — `BLUFOR`.
- **Dimension** — `LAND`.
- **Icons** — отметьте `RECON`.

С этими настройками группа получит условный знак наземной разведки стороны BLUFOR.

### Состав группы {#group-members}

В группе Alpha шесть бойцов. В предыдущих главах мы создали префабы командира и связиста. В готовой миссии есть ещё четыре специалиста: сержант по оперативным вопросам, пулемётчик, инженер и медик. Их префабы созданы по аналогии с этими двумя персонажами.

Если повторяете состав Alpha, сначала подготовьте эти четыре префаба, используя имена из таблицы ниже, и настройте снаряжение для их должностей. Для своего подразделения подберите [префабы персонажей](/lite-lobby-ar/ru/create-mission/base-character/) с нужными ролями и снаряжением. Когда все префабы будут готовы, добавьте их в группу.

Очистите поле поиска компонентов и выберите сам объект **SCR_AIGroup**. Раскройте **Group Members → Unit Prefab Slots** и с помощью кнопки `+` добавьте шесть строк.

Откройте в своём аддоне папку `Prefabs/Characters/Factions/BLUFOR/US_Army/Green Berets` и перетащите из неё префабы в строки списка в следующем порядке:

| Строка | Префаб |
| --- | --- |
| `0` | `TSS_Character_US_GB_DetachmentCommander.et` |
| `1` | `TSS_Character_US_GB_OperationsSergeant.et` |
| `2` | `TSS_Character_US_GB_WeaponsSergeant_M249.et` |
| `3` | `TSS_Character_US_GB_EngineerSergeant.et` |
| `4` | `TSS_Character_US_GB_MedicalSergeant.et` |
| `5` | `TSS_Character_US_GB_CommsSergeant.et` |

Каждая строка соответствует одному бойцу. Если состав вашего подразделения отличается от примера, укажите префабы нужных вам персонажей.

### Проверка группы {#test-group}

[Запустите миссию и откройте Game Master](/lite-lobby-ar/ru/create-mission/character-editor/#test-characters). Нажмите `Tab`, чтобы открыть **Entity Browser**. Выберите фракцию **US** и тип **Group**. Если после проверки персонажей остался включён фильтр **Character**, отключите его.

Найдите группу по её названию в поле **Search**. Для примера введите `Альфа` или `Alpha` — в зависимости от языка игры.

<LL_Screenshot

Выберите свою группу и щёлкните левой кнопкой мыши по земле, чтобы разместить её. Должны появиться все бойцы, указанные в списке **Unit Prefab Slots**; в примере Alpha их шесть. Проверьте их состав и снаряжение. Если кого-то не хватает, проверьте [список префабов группы](/lite-lobby-ar/ru/create-mission/groups-and-slots/#group-members).

## Группы в мире и игровые слоты {#playable-forces}

Группу проверили в Game Master. Теперь остановите игру и вернитесь в World Editor: подразделения, которые должны присутствовать в миссии с самого начала, нужно разместить в самом мире.

На Alpha разберём размещение и настройку слотов. На следующих скриншотах также показаны **Company HQ** и **Split Team Bravo** из готовой миссии. Если хотите повторить весь состав, подготовьте эти группы по аналогии с Alpha, указав для каждой свои название и состав.

В примере участвуют US и USSR. Для своей миссии соберите группы нужных сторон из игровых префабов персонажей. Для последующей проверки триггеров, сравнивающих численность, понадобятся игровые подразделения обеих сторон.

### Доступность персонажей в лобби {#playable-characters}

Откройте префаб персонажа в своём аддоне. Если бойцы наследуют настройки от одной основы, откройте её: в нашем примере это `TSS_Character_US_GB_BaseLoadout.et`. В панели **Object Properties** найдите компонент **LL_PlayableComponent**, добавленный Lite Lobby, и включите **Is Playable**. Эту настройку унаследуют персонажи, созданные на основе данного префаба.

Если используете исходных персонажей игры, сначала создайте их [наследников в своём аддоне](/lite-lobby-ar/ru/create-mission/base-character/#create-base-prefab) и [укажите их в составе группы](/lite-lobby-ar/ru/create-mission/groups-and-slots/#group-members). Так настройки игровых слотов будут относиться к вашим персонажам.

<LL_Screenshot
  src={step106}
  alt="В базовом префабе персонажа у LL_PlayableComponent включён Is Playable."
  caption="Персонаж будет доступен как слот в лобби."
  originalLabel="Открыть оригинал изображения"
/>

У персонажей, которыми должен управлять только ИИ, отключайте **Is Playable**. Сохраните префаб и вернитесь к редактированию мира миссии.

### Размещение групп и позывные {#group-callsigns}

Создайте слой `US` и сделайте его активным. В своём аддоне откройте папку `Prefabs/Groups/BLUFOR/Green Berets`, найдите префаб Alpha и перетащите его на стартовую позицию группы. Если вы также подготовили управление роты и Bravo, разместите их тем же способом.

Выберите размещённую группу и задайте ей имя вверху панели **Object Properties**. Затем выберите компонент **LL_GroupCallsign**. Если его нет, нажмите **Add Component** и добавьте его. Настройте каждую размещённую группу. Для Alpha используйте её строку из таблицы; остальные строки показывают настройки полного состава из примера:

| Группа | Имя объекта | **Company** | **Platoon** | **Squad** |
| --- | --- | --- | --- | --- |
| Управление роты | `AB_PL1` | `0` | `0` | `0` |
| Alpha | `AB_S1` | `0` | `1` | `0` |
| Bravo | `AB_S2` | `0` | `1` | `1` |

Числа в полях **Company**, **Platoon** и **Squad** указывают на элементы списков позывных фракции. Нумерация начинается с нуля. Со значениями из таблицы управление роты получит позывной **Atlas Red 1**, Alpha — **Atlas White 1**, а Bravo — **Atlas White 2**.

Названия полей относятся к системе позывных игры. Здесь мы используем её для управления роты и двух половин ODA. Поле **Platoon** не означает, что в организационной структуре нашего подразделения появился взвод.

Задавайте эти значения у **размещённых групп**. Это позволит назначить разные позывные нескольким группам, созданным из одного префаба. Имя `AB_S1` используется для ссылок на объект в редакторе, а позывной **Atlas White 1** отображается для игроков.

Чтобы добавить ещё одну ODA, снова разместите Alpha и Bravo. Задайте им новые имена объектов и другие сочетания чисел для позывных. Например, для следующей пары укажите **Platoon** `2`, а в поле **Squad** — `0`/`1` для Alpha и Bravo соответственно.

Если для вашей миссии подготовлены группы советской стороны, разместите их тем же способом в отдельном слое `USSR`. У персонажей, предназначенных для игроков, также должен быть включён **Is Playable**. Одной Alpha достаточно для проверки списка слотов ниже; к проверке триггеров численности переходите после размещения групп обеих сторон.

### Проверка списка слотов {#check-slots}

Нажмите зелёную кнопку запуска в **World Editor**. Если лобби не открылось, нажмите `U`. Проверьте, что группы отображаются на нужных сторонах, позывные назначены верно, а у персонажей указаны нужные роли и снаряжение.

  originalLabel="Открыть оригинал изображения"

Если группы нет в списке, проверьте, включён ли **Is Playable** у её персонажей, и откройте список **Unit Prefab Slots** в префабе группы. Убедитесь, что нужные персонажи входят в состав группы и принадлежат фракции.

## Техника подразделений {#squad-vehicles}

Технику можно закрепить за [группой, размещённой в мире](/lite-lobby-ar/ru/create-mission/groups-and-slots/#playable-forces). Тогда игроки будут видеть машины своего подразделения в лобби. Для настройки потребуется имя объекта группы из панели **Hierarchy**.

Если вы ещё проверяете миссию в игре, остановите её и вернитесь в редактор. В панели **Resource Browser** найдите нужную машину и перетащите её на карту рядом с группой. На скриншоте используется `S105_darkred.et` из проекта **ArmaReforger**.

Выберите машину, а затем её компонент **LL_VehicleSquadLinkComponent** в панели **Object Properties**. Если компонента нет, добавьте его через **Add Component**. В поле **Group Name** введите имя размещённой группы: `AB_S1` для Alpha или `AB_S2` для Bravo, если вы её подготовили и разместили. После этого машина появится в лобби среди техники этой группы.

<LL_Screenshot

Выберите компонент **SCR_VehicleFactionAffiliationComponent** и укажите `US` в поле **Faction affiliation**. Для техники советской стороны используйте значение `USSR`.

<LL_Screenshot

  caption="Принадлежность машины американской стороне."

Настройте остальные машины тем же способом. В поле **Group Name** указывайте имя объекта группы из панели **Hierarchy**. Позывной группы или имя файла её префаба для этого поля не подходят.

## Стартовые зоны и фризтайм

Когда группы и техника размещены, обозначим стартовые зоны и зададим время на подготовку игроков.

### Стартовая зона {#freeze-zone}

После перехода от брифинга к игре начинается фризтайм — время, отведённое игрокам на подготовку. Пока он не закончится, игроки должны оставаться в стартовой зоне.

В **ArmaReforger → PrefabsEditable → RestrictionZone** найдите `E_EditorRestrictionZoneLarge.et` и перетащите его на стартовую позицию. Расположите зону так, чтобы бойцы и техника находились внутри внутреннего круга. Если у подразделений разные стартовые позиции, добавьте отдельную зону для другой позиции.

Жёлтая граница показывает, где игрок получит предупреждение о выходе из зоны. Выход за красную границу опасен для персонажа. Когда фризтайм закончится, Lite Lobby удалит эти зоны, и игроки смогут покинуть стартовые позиции.

### Длительность фризтайма {#freeze-duration}

В панели **Hierarchy** выберите игровой режим `LL_GameMode_Lobby1`, а в **Object Properties** — компонент **LL_GameModeCoop**. Параметр **Freeze Time** задаёт длительность фризтайма в миллисекундах: значение `120000` соответствует двум минутам.

Параметр **Hard Freeze Time** задаёт начальную паузу, во время которой управление заблокировано, чтобы мир успел загрузиться. Эта пауза входит в общее время фризтайма.

Сохраните мир нажатием `Ctrl+S`.

Группы, игровые слоты и стартовые позиции настроены. Дальше добавим обозначения на карту, условия выполнения задач и брифинг.
