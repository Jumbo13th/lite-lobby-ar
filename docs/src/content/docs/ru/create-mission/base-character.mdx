[К оглавлению руководства](../)

Создадим персонажей для подразделения «зелёных беретов» в аддоне **[Triad Shooting Star](https://github.com/Jumbo13th/triad-shooting-star-ar)**. Используем фракцию США, которая уже есть в игре. О выборе подразделения и подборе снаряжения можно прочитать в [отдельной справке](/lite-lobby-ar/ru/character-prefabs/planning/).

**Префаб персонажа** — шаблон бойца: его внешний вид, снаряжение и другие настройки. Он хранится в файле `.et`. Сначала подготовим общий префаб с формой и личными вещами — `BaseLoadout`. На его основе создадим варианты с разным вооружением.

## Названия и папки {#naming-and-folders}

Чтобы отличать свои файлы от игровых, добавляйте в начало имени **префикс аддона** — короткое обозначение вашего проекта. Для аддона **[Triad Shooting Star](https://github.com/Jumbo13th/triad-shooting-star-ar)** используем первые буквы его названия: `TSS_`. Для своего проекта выберите своё сокращение, например **Desert Storm** → `DS_`.

Остальную часть имени оформляйте по образцу файлов игры: `Character_US_Rifleman.et` → `TSS_Character_US_Rifleman.et`. Сохраняйте заглавные буквы, подчёркивания и порядок частей имени. Один и тот же префикс используйте для всех префабов своего аддона.

Структуру папок также повторяйте по образцу игры. Например, префабы армии США находятся в `Prefabs/Characters/Factions/BLUFOR/US_Army`. Размещайте свои варианты по тому же пути внутри аддона, чтобы их было легко найти и сопоставить с игровыми префабами.

## Создание базового префаба {#create-base-prefab}

В качестве исходного префаба возьмём игровой `Character_US_Base.et`. Создадим его [наследника](/lite-lobby-ar/ru/character-prefabs/prefab-operations/#inherit-prefab) — новый префаб, который получит настройки исходного персонажа. Форму и снаряжение будем менять уже в нём.

В панели **Resource Browser** редактора **World Editor** откройте проект **ArmaReforger**, затем папку `Prefabs/Characters/Factions/BLUFOR/US_Army`. Щёлкните правой кнопкой мыши по `Character_US_Base.et` и выберите **Inherit in → ваш аддон**. На скриншоте наш аддон указан как **TriadShootingStar**.

<LL_Screenshot
  src={inheritCharacter}
  alt="В Resource Browser выбран Character_US_Base.et; в контекстном меню открыт пункт Inherit in → TriadShootingStar."
  caption="Создание префаба на основе Character_US_Base.et."
  originalLabel="Открыть оригинал изображения"
/>

В окне **Create inherited file** введите `TSS_Character_US_GB_BaseLoadout` в поле **File Name** и нажмите **OK**. Для своего аддона замените `TSS_` на выбранный префикс. Здесь `GB` означает Green Berets, а `BaseLoadout` — базовый набор снаряжения.

<LL_Screenshot
  src={nameCharacter}
  alt="В окне Create inherited file введено имя TSS_Character_US_GB_BaseLoadout."
  caption="Название базового префаба персонажа."
  originalLabel="Открыть оригинал изображения"
/>

Workbench создаст в вашем аддоне файл `TSS_Character_US_GB_BaseLoadout.et`. Он будет находиться в папке `Prefabs/Characters/Factions/BLUFOR/US_Army`: при наследовании редактор автоматически повторяет путь исходного префаба.

<Aside type="tip" title="Как открыть папку префаба">
Выберите объект в мире или префаб в **Resource Browser** и нажмите `L`. В **Resource Browser** откроется папка этого префаба.
</Aside>

### Папка подразделения {#unit-folder}

Для префабов нашего подразделения создадим отдельную папку. В **Resource Browser** откройте `Prefabs/Characters/Factions/BLUFOR/US_Army` своего аддона. Щёлкните правой кнопкой мыши по пустому месту в списке файлов, выберите создание папки и назовите её `Green Berets`.

Перетащите `TSS_Character_US_GB_BaseLoadout.et` в папку `Green Berets`, затем откройте её.

## Форма персонажа {#base-outfit}

Дважды щёлкните по `TSS_Character_US_GB_BaseLoadout.et` в **Resource Browser**. В открывшемся окне нажмите **Edit Prefab** справа. Откроется **World Editor** в режиме редактирования префаба.

<LL_Screenshot
  src={editCharacter}
  alt="Открыт TSS_Character_US_GB_BaseLoadout.et; стрелка указывает на кнопку Edit Prefab справа."
  caption="Переход к редактированию префаба."
  originalLabel="Открыть оригинал изображения"
/>

В панели **Hierarchy** выберите персонажа. Затем в строке поиска компонентов панели **Object Properties** введите `load` и выберите **BaseLoadoutManagerComponent**. Этот компонент определяет, что надето на персонаже.

Раскройте список **Slots**. Каждый его пункт — слот для определённого предмета экипировки. Например, **Hat** предназначен для головного убора, а **Jacket** — для куртки. Раскройте **Hat**. Поле **Prefab** задаёт предмет в этом слоте.

### Брюки, ботинки и рюкзак {#pants-boots-backpack}

Остальные предметы назначаются тем же способом: раскройте слот и перетащите нужный префаб в его поле **Prefab**. Заполните ещё три слота по таблице. Все перечисленные файлы находятся в проекте **ArmaReforger**:

| Слот | Папка | Файл |
| --- | --- | --- |
| **Pants** — брюки | `Prefabs/Characters/Uniforms` | `Pants_US_BDU.et` |
| **Boots** — ботинки | `Prefabs/Characters/Footwear` | `CombatBoots_US_01.et` |
| **Back** — рюкзак | `Prefabs/Items/Equipment/Backpacks` | `Backpack_ALICE_Medium_assembled.et` |

## Радиостанция {#radio-setup}

У игровой радиостанции два канала. Боец может использовать первый для связи со своим подразделением, а второй — со всей стороной одновременно. В нашей миссии такая возможность не нужна: оставим один канал, чтобы упростить игру.

Для этого создадим собственный вариант радиостанции. В **Resource Browser** откройте проект **ArmaReforger** и папку `Prefabs/Items/Equipment/Radios`. Щёлкните правой кнопкой мыши по `Radio_ANPRC68.et` и выберите **Duplicate to → ваш аддон**. Команда создаст копию префаба в вашем аддоне.

  src={duplicateRadio}
  alt="В контекстном меню Radio_ANPRC68.et выбран пункт Duplicate to → TriadShootingStar."
  caption="Копирование радиостанции в аддон миссии."
  originalLabel="Открыть оригинал изображения"
/>

В окне **Duplicate File** укажите имя `TSS_Radio_ANPRC68` и нажмите **OK**.

<LL_Screenshot

Раскройте **Unsorted → Transceivers** — список приёмопередатчиков. Наведите курсор на второй **RadioTransceiver**, перечёркнутый на скриншоте, и нажмите `Delete` на клавиатуре.

## Содержимое инвентаря {#initial-inventory}

Добавим радиостанцию и остальные вещи в карманы брюк персонажа. Откройте `TSS_Character_US_GB_BaseLoadout.et` через **Edit Prefab**. Выберите персонажа в **Hierarchy**, в поиске компонентов введите `InventoryStora` и выберите **SCR_InventoryStorageManagerComponent**. Здесь задаются начальный набор предметов и места их хранения.

1. В списке **Initial Inventory Items** нажмите `+`. Появится запись **ItemsInitConfigurationItem**; раскройте её.
2. В поле **Target Storage** выберите `Pants/Pants_US_BDU.et`. Предметы из этой записи окажутся в карманах брюк.
3. В списке **Prefabs To Spawn** добавьте 12 строк кнопкой `+`. Каждая строка задаёт один предмет из нашего набора.

<LL_Screenshot
  src={inventorySetup}
  alt="В SCR_InventoryStorageManagerComponent выбран Target Storage Pants/Pants_US_BDU.et и добавлены пустые строки Prefabs To Spawn."
  caption="Выбор места для предметов и добавление строк."
  originalLabel="Открыть оригинал изображения"
/>

Заполните **Prefabs To Spawn** предметами из таблицы: найдите каждый префаб в **Resource Browser** и перетащите его в строку списка. Для поиска выберите нужный проект и введите имя файла. Радиостанция находится в вашем аддоне, остальные предметы — в проекте **ArmaReforger**.

| Предмет | Префаб | Количество |
| --- | --- | --- |
| Радиостанция | `TSS_Radio_ANPRC68.et` | 1 |
| Компас | `Compass_SY183.et` | 1 |
| Карта | `PaperMap_01_folded_US.et` | 1 |
| Бинт | `FieldDressing_US_01.et` | 4 |
| Морфин | `MorphineInjection_01_base.et` | 2 |
| Жгут | `Tourniquet_US_01.et` | 2 |
| Сапёрная лопатка | `ETool_ALICE_FreeRoamBuilding_Gadget.et` | 1 |

Чтобы добавить несколько одинаковых предметов, повторите их префаб в нескольких строках. Например, для четырёх бинтов нужно заполнить четыре строки одним и тем же файлом.

## Наручные часы {#wristwatch}

Часы назначаются в отдельном слоте экипировки. В списке компонентов персонажа раскройте **SCR_CharacterInventoryStorageComponent** и выберите вложенный **SCR_EquipmentStorageComponent**. В его свойствах раскройте **Initial Storage Slots → WristwatchSlot** — слот наручных часов.

В **Resource Browser** выберите **ArmaReforger** и найдите `Watch_SandY184A.et`. Перетащите его в поле **Prefab** слота **WristwatchSlot**.

<LL_Screenshot
  src={characterWatch}
  alt="В SCR_EquipmentStorageComponent для WristwatchSlot назначен префаб Watch_SandY184A.et."
  caption="Наручные часы персонажа."
  originalLabel="Открыть оригинал изображения"
/>

Нажмите `Ctrl+S`, чтобы сохранить префаб персонажа.
