[К оглавлению руководства](../)

Зададим названия и роли персонажей, добавим их в каталог Game Master и проверим в игре. Затем соберём из готовых персонажей группу и проверим её состав.

## Таблица переводов {#character-localization}

**Таблица переводов** хранит варианты текста для разных языков. Создадим одну таблицу для персонажей и групп аддона **[Triad Shooting Star](https://github.com/Jumbo13th/triad-shooting-star-ar)**.

Первой записью в таблице станет название связиста: «Сержант связи» и **Communications Sergeant**. Игра выберет нужный вариант в зависимости от языка игрока.

### Название на двух языках {#localization-entry}

Каждой строке таблицы нужен **ключ** — уникальное обозначение, по которому игра найдёт её переводы. В поле **Insert** введите `TSS-Characters_CommsSergeant` без `#` и нажмите кнопку **Insert**.

Выберите добавленную строку слева и заполните поля справа:

- **Target En Us** — `Communications Sergeant`.
- **Translated Texts → Target Ru Ru** — `Сержант связи`.

### Сборка файлов переводов {#build-runtime-table}

Нажмите `Ctrl+S`, чтобы сохранить таблицу. Затем выберите **Table → Build Runtime Table** (`Ctrl+B`). Редактор создаст файлы переводов для игры. После каждого изменения текста сохраняйте таблицу и повторяйте сборку.

### Подключение таблицы к проекту {#register-localization}

Чтобы игра загрузила переводы, подключим таблицу в настройках аддона. В главном окне Workbench откройте **File → Project Settings**. В поле **Project** выберите свой аддон, а в **Configuration** — **PC**.

1. Раскройте **Widget Manager Settings → String Tables** и нажмите `+`.
2. Откройте новую запись. У поля **String Table Source** нажмите `…` и выберите `Language/tss_localization.st` из своего аддона.
3. В списке **Languages** этой записи добавьте английский и русский языки. Для каждого заполните **Code** и укажите в **String Table Runtime** соответствующий файл переводов:

| Code | String Table Runtime |
| --- | --- |
| `en_us` | `Language/tss_localization.en_us.conf` |
| `ru_ru` | `Language/tss_localization.ru_ru.conf` |

Если эти записи уже заполнены, добавлять их повторно не нужно. Нажмите **OK**.

## Названия и роли в префабах {#editor-character-properties}

Название и роль персонажа задаются в разделе **SCR_EditableCharacterComponent → Visualization → UI Info**:

- **Name** — название персонажа.
- **Authored Labels** — метки персонажа, в том числе его роль.

### Роль персонажа {#comms-role}

Откройте `TSS_Character_US_GB_CommsSergeant.et` через **Edit Prefab** и выберите персонажа. В поиске компонентов введите `edita`, выберите **SCR_EditableCharacterComponent** и раскройте **Visualization → UI Info**.

В списке **Authored Labels** замените `ROLE_RIFLEMAN` на `ROLE_RADIOOPERATOR`. Эта метка обозначает связиста в игровом редакторе.

  originalLabel="Открыть оригинал изображения"
/>

### Название из таблицы переводов {#localized-character-name}

В **Name** пока указано `#AR-Role_Rifleman` — ссылка на игровое название «Стрелок». Замените её на `#TSS-Characters_CommsSergeant`.

В этом поле перед ключом ставится `#`: так игра отличает ссылку на перевод от обычного текста. Сам ключ после `#` должен точно совпадать с **Id** строки в String Editor.

- В **Name** укажите `#TSS-Characters_DetachmentCommander`.
- В **Authored Labels** замените `ROLE_RIFLEMAN` на `ROLE_LEADER`.

## Добавление персонажей в каталог {#character-catalog}

Чтобы находить и размещать бойцов через **Game Master**, добавим их в каталог фракции США.

Для каждого префаба персонажа нужна отдельная запись каталога. В ней указываются файл префаба и настройки его доступности в игровом редакторе.

### Оверрайд каталога {#override-character-catalog}

В **Resource Browser** выберите проект **ArmaReforger** и откройте папку `Configs/EntityCatalog/US`. Щёлкните правой кнопкой мыши по `Characters_EntityCatalog_US.conf` и выберите **Override in → ваш аддон**.

<LL_Screenshot
  src={overrideCharacterCatalog}
  alt="Для Characters_EntityCatalog_US.conf выбрана команда Override in с выбором аддона."
  caption="Оверрайд каталога персонажей США."
  originalLabel="Открыть оригинал изображения"
/>

Здесь нужен [оверрайд](/lite-lobby-ar/ru/character-prefabs/prefab-operations/#override-prefab): мы дополняем каталог, который игра уже использует. Поэтому имя `Characters_EntityCatalog_US.conf` сохраняем без префикса `TSS_`.

### Добавление бойцов {#catalog-entries}

Перейдите в папку `Configs/EntityCatalog/US` своего аддона и двойным щелчком откройте `Characters_EntityCatalog_US.conf`. В списке **Entity Entry List** найдите запись `Character_US_SF_Sapper_S.et`, щёлкните по ней правой кнопкой мыши и выберите **Duplicate**.

<LL_Screenshot
  src={duplicateCatalogEntry}
  alt="В контекстном меню записи Character_US_SF_Sapper_S.et выбрана команда Duplicate."
  caption="Копирование готовой записи каталога."
  originalLabel="Открыть оригинал изображения"
/>

Команда копирует только запись каталога; новый файл префаба при этом не создаётся. В полученной записи укажем уже подготовленного связиста.

Раскройте добавленную запись. В **Resource Browser** откройте папку `Green Berets` своего аддона и перетащите `TSS_Character_US_GB_CommsSergeant.et` в поле **Entity Prefab**.

<LL_Screenshot
  src={assignCatalogPrefab}
  alt="Префаб персонажа перетаскивают из Resource Browser в поле Entity Prefab записи каталога."
  caption="Назначение префаба. На скриншоте показан заместитель командира; мы добавляем связиста."
  originalLabel="Открыть оригинал изображения"
/>

Вместе с записью скопированы настройки **Entity Data List** для игрового редактора. Для наших бойцов подходят те же значения.

Скопируйте полученную запись командой **Duplicate**. В копии замените значение **Entity Prefab** на `TSS_Character_US_GB_DetachmentCommander.et`. Теперь в каталоге есть две отдельные записи: для связиста и для командира.

<LL_Screenshot
  src={characterCatalogRoster}
  alt="В каталоге добавлены префабы персонажей миссии Triad Shooting Star."
  caption="Полный набор бойцов примера миссии. На этом этапе у нас добавлены двое."
  originalLabel="Открыть оригинал изображения"
/>

Остальных бойцов добавляйте так же, по мере готовности их префабов. В `BaseLoadout` и `ODA_Base` собраны общие настройки для персонажей разных должностей; сами эти префабы в каталог не добавляем.

Сохраните каталог нажатием `Ctrl+S`.

## Проверка в игре {#test-characters}

Откройте в **World Editor** мир своей миссии и нажмите зелёную кнопку запуска на верхней панели.

<LL_Screenshot
  src={launchCharacterTest}
  alt="В World Editor открыт мир миссии; стрелкой отмечена зелёная кнопка запуска."
  caption="Запуск миссии для проверки персонажей."
  originalLabel="Открыть оригинал изображения"
/>

### Поиск персонажей {#find-test-characters}

После запуска миссии нажимайте **Play** в самом лобби, пока не начнётся игра. Затем нажмите `Y`, чтобы открыть **Game Master**.

`U` открывает и закрывает лобби, а `Y` — Game Master.

В **Game Master** нажмите `Tab`, чтобы открыть **Entity Browser** — каталог объектов для размещения. В фильтрах справа выберите фракцию **US** и тип **Character**.

Найдите обоих бойцов через поле **Search**, вводя их названия: «Сержант связи» и «Командир отряда». Если игра работает на английском языке, ищите **Communications Sergeant** и **Detachment Commander**.

<LL_Screenshot
  src={testCharacterBrowser}
  alt="В Entity Browser выбрана фракция US; среди персонажей видны Communications Sergeant и Detachment Commander."
  caption="Персонажи примера миссии в игровом каталоге."
  originalLabel="Открыть оригинал изображения"
/>

Надпись `PLACE HOLDER` вместо миниатюры означает, что для префаба ещё не подготовлено изображение. Выбрать такую карточку и разместить бойца можно обычным способом.

Если бойца нет в списке, проверьте его запись в [каталоге персонажей](#catalog-entries). Если вместо названия виден ключ с `#`, проверьте [ссылку на перевод](#localized-character-name).

### Размещение персонажей {#place-test-characters}

Выберите карточку бойца, наведите курсор на землю и щёлкните левой кнопкой мыши, чтобы разместить его в мире. Таким же способом добавьте второго персонажа. Щелчок правой кнопкой мыши отменяет размещение.

<LL_Screenshot
  src={placedTestCharacters}
  alt="В Game Master на местности размещены персонажи миссии Triad Shooting Star."
  caption="Проверка внешнего вида. На скриншоте весь набор примера; нам пока нужны связист и командир."
  originalLabel="Открыть оригинал изображения"
/>

Осмотрите обоих персонажей и сверьте их снаряжение с настройками префабов. У связиста должны быть ранцевая радиостанция, кепка и куртка с закатанными рукавами, а у командира — M72A3 и бинокль.

## Префаб группы {#group-prefab}

Префаб группы объединяет префабы персонажей и позволяет разместить всех бойцов сразу. Создадим группу «Альфа» (**Split Team Alpha**) — первую половину отряда ODA из миссии **[Triad Shooting Star](https://github.com/Jumbo13th/triad-shooting-star-ar)**.

### Создание префаба {#create-group-prefab}

Остановите тестовый запуск игры и вернитесь в **World Editor**.

В проекте **ArmaReforger** откройте папку `Prefabs/Groups/BLUFOR`. Щёлкните правой кнопкой мыши по `Group_US_Base.et` и выберите **Inherit in → ваш аддон**.

<LL_Screenshot

<LL_Screenshot

В своём аддоне откройте папку `Prefabs/Groups/BLUFOR`. Щёлкните правой кнопкой мыши по свободному месту в **Resource Browser**, создайте папку `Green Berets` и перетащите в неё новый префаб.

### Название группы {#group-name}

Откройте `Language/tss_localization.st` в **String Editor**. [Добавьте строку](/lite-lobby-ar/ru/create-mission/character-editor/#localization-entry) с ключом `TSS-Groups_SplitTeamAlpha`:

- **Target En Us** — `Split Team Alpha`.
- **Target Ru Ru** — `Группа «Альфа»`.

Сохраните таблицу нажатием `Ctrl+S`, затем нажмите `Ctrl+B`, чтобы обновить файлы переводов для игры.

<LL_Screenshot

  originalLabel="Открыть оригинал изображения"
/>

Откройте `TSS_Group_US_GB_SplitTeamAlpha.et` через **Edit Prefab** и выберите объект группы. В поиске компонентов введите `edita`, выберите **SCR_EditableGroupComponent** и раскройте **Visualization → UI Info**.

В поле **Name** укажите `#TSS-Groups_SplitTeamAlpha`. В списке **Authored Labels** нажмите `+` и добавьте метку `GROUPSIZE_LARGE`, как в примере. Эта метка задаёт категорию размера группы в игровом редакторе.

### Условный знак {#group-symbol}

Ниже включите параметр **Use UI Info Name**, чтобы для группы использовалось название из поля **Name**. Затем в разделе **Military Symbol** задайте параметры условного знака:

- **Identity** — `BLUFOR`.
- **Dimension** — `LAND`.
- **Icons** — отметьте `RECON`.

С этими настройками группа получит условный знак наземной разведки стороны BLUFOR.

### Состав группы {#group-members}

В группе «Альфа» шесть бойцов. В предыдущих главах мы создали префабы командира и связиста. В готовой миссии есть ещё четыре специалиста: сержант по оперативным вопросам, пулемётчик, инженер и медик. Их префабы созданы по аналогии с этими двумя персонажами.

Для полного состава группы «Альфа» подготовьте ещё четыре [префаба персонажей](/lite-lobby-ar/ru/create-mission/base-character/) с именами из таблицы ниже. Подберите снаряжение для каждой должности, затем добавьте бойцов в группу.

Очистите поле поиска компонентов и выберите сам объект **SCR_AIGroup**. Раскройте **Group Members → Unit Prefab Slots** и с помощью кнопки `+` добавьте шесть строк.

Откройте в своём аддоне папку `Prefabs/Characters/Factions/BLUFOR/US_Army/Green Berets` и перетащите из неё префабы в строки списка в следующем порядке:

| Строка | Префаб |
| --- | --- |
| `0` | `TSS_Character_US_GB_DetachmentCommander.et` |
| `1` | `TSS_Character_US_GB_OperationsSergeant.et` |
| `2` | `TSS_Character_US_GB_WeaponsSergeant_M249.et` |
| `3` | `TSS_Character_US_GB_EngineerSergeant.et` |
| `4` | `TSS_Character_US_GB_MedicalSergeant.et` |
| `5` | `TSS_Character_US_GB_CommsSergeant.et` |

Каждая строка соответствует одному бойцу. Если состав вашего подразделения отличается от примера, укажите префабы нужных вам персонажей.

### Проверка группы {#test-group}

[Запустите миссию и откройте Game Master](/lite-lobby-ar/ru/create-mission/character-editor/#test-characters). Нажмите `Tab`, чтобы открыть **Entity Browser**. Выберите фракцию **US** и тип **Group**. Если после проверки персонажей остался включён фильтр **Character**, отключите его.

Найдите группу по её названию в поле **Search**. Для примера введите `Альфа` или `Alpha` — в зависимости от языка игры.

<LL_Screenshot
  src={groupBrowser}
  alt="В Entity Browser видны группы Company HQ, Split Team Alpha и Split Team Bravo."
  caption="Группы миссии Triad Shooting Star в игровом каталоге."
  originalLabel="Открыть оригинал изображения"

Выберите свою группу и щёлкните левой кнопкой мыши по земле, чтобы разместить её. Должны появиться все бойцы, указанные в списке **Unit Prefab Slots**; в группе «Альфа» их шесть. Проверьте их состав и снаряжение. Если кого-то не хватает, проверьте [список префабов группы](/lite-lobby-ar/ru/create-mission/character-editor/#group-members).
