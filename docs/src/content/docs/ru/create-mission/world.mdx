В подготовленном аддоне создадим мир миссии, добавим игровой режим Lite Lobby и настроим карту. В примере используем Эверон.

## Создание мира {#create-world}

В Workbench миром называют карту вместе с размещёнными на ней объектами. Возьмём карту Эверона из игры и создадим на её основе отдельную сцену. В ней будут храниться объекты нашей миссии.

### Открытие карты {#open-world-editor}

В главном окне Workbench нажмите **World Editor** в блоке **Quick Launch**. Это редактор, в котором мы будем размещать объекты миссии.

В панели **Resource Browser** откройте `ArmaReforger/worlds/Eden` и дважды щёлкните `Eden.ent`. Дождитесь загрузки карты.

<LL_Screenshot

### Создание отдельной сцены {#create-subscene}

Выберите **File → New World**.

В окне **Create world** выберите **Sub-scene (of current world)** и нажмите **OK**. Новая сцена будет использовать открытую карту, а добавленные нами объекты сохранит отдельно от неё.

### Сохранение мира {#save-world}

Нажмите `Ctrl+S`.

В окне сохранения откройте свой проект. Кнопкой **New Folder** создайте папку `Worlds`, а внутри неё — папку `Eden`. Откройте `Eden`, в поле **File name** введите `ShootingStar_Ep1` и нажмите **OK**.

<Aside type="tip" title="Названия файлов и структура папок">
Для файла мира выберите название вроде `DesertStorm` или `SilentPort`: начинайте каждое слово с заглавной буквы и не ставьте пробелы между словами. Не используйте имена `test_world`, `tempworld` или `Temp World`. Расположите файл так же, как на скриншоте: `Worlds` → `Eden` → файл мира. Переименование файлов и папок может вызывать проблемы в движке, поэтому окончательные названия лучше выбрать сразу.

Для сервера Triad Tactics рекомендуем указывать в имени номер эпизода: `DesertStorm_Ep1`, `DesertStorm_Ep2`, `DesertStorm_Ep3`. Игры на сервере состоят из трёх эпизодов. Если вы создаёте миссию для другого сервера, `_Ep1` можно опустить.
</Aside>

### Слой для систем миссии {#systems-layer}

Чтобы объекты было проще находить, их распределяют по слоям. Для [системных объектов миссии](/lite-lobby-ar/ru/create-mission/world/#game-mode-setup) подготовим слой с именем `a_systems`.

В панели **Hierarchy** найдите слой `default` внутри своей сцены `ShootingStar_Ep1`. Нажмите на него правой кнопкой мыши и выберите **Rename**. Введите `a_systems` и нажмите **OK**.

<LL_Screenshot

  caption="Слой a_systems для системных объектов миссии."
  originalLabel="Открыть оригинал изображения"

В панели **Hierarchy** дважды щёлкните по слою `a_systems`, чтобы сделать его активным. Мастер добавит новые объекты в этот слой.

Выберите **Plugins → Game Mode Setup**.

## Добавление игрового режима Lite Lobby {#lite-lobby-game-mode}

Мастер добавил в мир игровой режим Game Master. Заменим его игровым режимом Lite Lobby.

В панели **Hierarchy** раскройте слой `a_systems`, выберите `GameMode_Editor_Full` и нажмите `Delete`. Вместе с игровым режимом удалятся его вложенные объекты, перечёркнутые на скриншоте. Объекты `MapEntity`, `PerceptionManager` и `SCR_AIWorld` находятся отдельно и останутся в слое.

<LL_Screenshot
  src={removeGameMaster}
  alt="В слое a_systems перечёркнут GameMode_Editor_Full с вложенными объектами; MapEntity, PerceptionManager и SCR_AIWorld находятся отдельно."
  caption="Удаление игрового режима Game Master."
  originalLabel="Открыть оригинал изображения"
/>

Дважды щёлкните по `a_systems`, чтобы сделать слой активным. В **Resource Browser** выберите проект **LiteLobby** и введите `GameMode` в строку поиска. Найдите `LL_GameMode_Lobby.et`.

Файл `.et` — это **префаб**, готовый шаблон объекта с настройками. Перетащите `LL_GameMode_Lobby.et` из **Resource Browser** на карту в окне редактора. В слое `a_systems` появится игровой режим Lite Lobby с вложенными системными объектами.

## Название и описание миссии {#mission-details}

В панели **Resource Browser** найдите в своём аддоне файл `Missions/ShootingStar_Ep1.conf`, созданный [мастером настройки](/lite-lobby-ar/ru/create-mission/world/#create-mission-header). Откройте его и заполните поля:

| Поле | Что указать |
| --- | --- |
| **World** | Файл мира вашей миссии. Мастер уже указал `ShootingStar_Ep1.ent`. |
| **Name** | Название миссии, которое увидят игроки в списке сценариев. |
| **Author** | Ваше имя или никнейм. |
| **Description** | Краткое описание: кто участвует в миссии и где происходит действие. |
| **Player Count** | На сколько игроков рассчитана миссия. В примере — `128`. |

Раздел **Save Types** оставьте как есть. В поле **Systems Config** укажите `LL_LobbySystems.conf`; писать ли снапшоты, решает флажок **Session saves** в игровом режиме.

<LL_Screenshot
  src={missionDetails}
  alt="Файл ShootingStar_Ep1.conf с заполненными полями World, Name, Author, Description, Player Count, нетронутыми Save Types и Systems Config = LL_LobbySystems.conf."
  caption="Название, описание и параметры миссии."
  originalLabel="Открыть оригинал изображения"
/>

Несколько правил, от которых зависит восстановление сессии:

- У каждого отряда должно быть уникальное имя сущности: при восстановлении сессии отряды находятся по имени.
- Отряды, создаваемые из скрипта, нужно создавать из хука старта игры лобби: при восстановлении сессии он не выполняется.
- Фризтайм отсчитывается от конца хардфриза: во время любого хардфриза время стоит.
- В миссиях лобби длительность игры на компоненте состояния игрового режима не задаётся.

Нажмите `Ctrl+S`, чтобы сохранить файл сценария.

## Настройка карты {#map-setup}

Объект `MapEntity` отвечает за карту, которую игроки открывают во время миссии. Для её отображения укажем готовые файлы Эверона.

Вернитесь в **World Editor**. В панели **Hierarchy** выберите `MapEntity` в слое `a_systems`. Справа, в **Object Properties**, найдите компоненты `SCR_CompassComponent` и `SCR_WristwatchComponent`, которые отвечают за компас и часы. Обычно они уже есть в списке. Если одного из них нет, нажмите **Add Component** внизу панели, найдите компонент по названию и выберите его.

Нажмите на верхнюю строку **SCR_MapEntity** в панели **Object Properties** и раскройте раздел **Unsorted**. Заполните два поля, выбирая файлы из проекта **ArmaReforger** через кнопку `…`:

- **Map Geometry Data** — `worlds/Eden/Eden.topo`. Здесь хранятся дороги, здания и другие объекты для отображения на карте.
- **Satellite background image** — `UI/Textures/Map/worlds/EveronRasterized.edds`. Это фон карты с рельефом и лесами.
