## Save changes {#save-commit-push}

We use the [GitHub Desktop](https://desktop.github.com/) app to work with Git.

Saving in the editor, creating a commit, and pushing to GitHub are three separate actions:

- **Save** in Workbench writes your current changes to the mission files.
- **Commit** in GitHub Desktop records selected changes in the repository history on your computer.
- **Push origin** sends those commits to the repository on GitHub.

After saving in Workbench, review your changes in GitHub Desktop and create a commit. It lets you restore that version after a bad edit or file deletion. Push the commit to GitHub to keep a copy in case data on your computer is lost.

[Official getting-started instructions for GitHub Desktop](https://docs.github.com/en/desktop/overview/creating-your-first-repository-using-github-desktop).
