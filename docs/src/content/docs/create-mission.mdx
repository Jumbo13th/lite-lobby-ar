## How to use this guide {#reading-paths}

In this guide, we recreate **[Triad Shooting Star](https://github.com/Jumbo13th/triad-shooting-star-ar)** from scratch, from opening the editor to publishing the mission in Workshop. It is written for people who have not used Arma Reforger Tools. You do not need programming experience to create a mission.

Follow the chapters in order: they build on one another.

We also recommend [opening the example mission](../example-mission/) alongside the guide. Some explanations are intended for beginners. You may find it easier to explore the finished mission and read the relevant chapters as needed.

Before starting, we recommend [setting up Git](../git/). It saves working versions of your mission so you can return to them if later changes break something, saving time and effort.

## Part I. Preparation {#preparation-part}

- [1. Prepare the project](project/) — install the tools, create the addon and add Lite Lobby.
- [2. Create a world with Lite Lobby](world/) — prepare the world, game mode, scenario header and map.

## Part II. Characters {#characters-part}

- [3. The base character](base-character/) — choose the clothing, personal radio and items shared by the soldiers.
- [4. Weapons and character variants](character-variants/) — add weapons and ammunition, then create a radio operator and a commander.
- [5. Character names and Game Master checks](character-editor/) — configure translations and roles, add the soldiers to the in-game editor and test them.

## Part III. Assemble and finish the mission {#mission-part}

- [6. Groups and playable slots](groups-and-slots/) — assemble and place units, assign callsigns and vehicles, and set starting zones.
- [7. Mission objectives and triggers](objectives/) — mark objectives on the map, configure conditions and prepare the briefing.
- [8. Test and publish](publishing/) — test the mission in Workbench and on a server, then publish the addon to Workshop.

## Further explanations

- [Choose a unit and its equipment](../character-prefabs/planning/) — select a roster, clothing and weapons for the period.
- [Inheritance, duplicate and override](../character-prefabs/prefab-operations/) — understand the different prefab operations.
