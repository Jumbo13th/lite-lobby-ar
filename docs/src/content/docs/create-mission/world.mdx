In the prepared addon, create the mission world, add Lite Lobby’s game mode and configure the in-game map. The example uses Everon.

## Create the world {#create-world}

A world contains the map and the objects placed on it. Use Everon from the game to create a separate scene for our mission objects.

### Open the map {#open-world-editor}

In the main Workbench window, click **World Editor** under **Quick Launch**. This is the editor where we will place mission objects.

  alt="The main Workbench window with an arrow pointing to World Editor under Quick Launch."
  caption="Starting World Editor."
  originalLabel="Open original image"
/>

In **Resource Browser**, open `ArmaReforger/worlds/Eden` and double-click `Eden.ent`. Wait for the map to load.

<LL_Screenshot
  src={baseWorld}
  alt="Resource Browser showing ArmaReforger/worlds/Eden with Eden.ent selected."
  caption="The Eden.ent map in the game files."
  originalLabel="Open original image"
/>

### Create a separate scene {#create-subscene}

Choose **File → New World**.

<LL_Screenshot
  src={newWorld}
  alt="The File menu with New World selected after loading Eden.ent."
  caption="Creating a world based on the open map."
  originalLabel="Open original image"
/>

In **Create world**, select **Sub-scene (of current world)** and click **OK**. This scene uses the open map and stores the objects we add separately.

<LL_Screenshot
  src={subscene}
  alt="The Create world dialog with Sub-scene (of current world) selected."

/>

### Save the world {#save-world}

Press `Ctrl+S`.

In the save dialog, open your project. Use **New Folder** to create a `Worlds` folder and an `Eden` folder inside it. Open `Eden`, enter `ShootingStar_Ep1` in **File name**, and click **OK**.

<Aside type="tip" title="File names and folder structure">
For the world file, use a name such as `DesertStorm` or `SilentPort`: capitalize each word without spaces. Avoid `test_world`, `tempworld`, or `Temp World`. Follow the folder structure in the screenshot: `Worlds` → `Eden` → world file. Renaming files and folders can cause problems in the engine, so choose their final names from the start.

For the Triad Tactics server, we recommend keeping the episode in the filename: `DesertStorm_Ep1`, `DesertStorm_Ep2`, `DesertStorm_Ep3`, as games have three episodes. For missions intended for other servers, you can omit `_Ep1`.
</Aside>

<LL_Screenshot
  src={saveWorld}
  alt="The Save world as dialog showing the project's Worlds/Eden folder and ShootingStar_Ep1 in File name."
  caption="Saving the world in your addon."
  originalLabel="Open original image"
/>

The world file will be at `Worlds/Eden/ShootingStar_Ep1.ent` inside your addon folder. **Hierarchy** will show our `ShootingStar_Ep1` scene alongside the base world, `Eden`.

### Mission systems layer {#systems-layer}

Layers organize scene objects into groups. Prepare `a_systems` for the [mission's system objects](/lite-lobby-ar/create-mission/world/#game-mode-setup).

In **Hierarchy**, find the `default` layer under your `ShootingStar_Ep1` scene. Right-click it and choose **Rename**. Enter `a_systems` and click **OK**.

<LL_Screenshot
  src={systemsLayer}

  caption="Renaming your scene's layer."

Press `Ctrl+S` to save the changes.

## Add the Lite Lobby game mode {#lite-lobby-game-mode}

The wizard added the Game Master game mode. Replace it with the Lite Lobby game mode.

In **Hierarchy**, expand `a_systems`, select `GameMode_Editor_Full`, and press `Delete`. This also removes its child objects, crossed out in the screenshot. The separate `MapEntity`, `PerceptionManager`, and `SCR_AIWorld` objects remain in the layer.

<LL_Screenshot
  src={removeGameMaster}
  alt="GameMode_Editor_Full and its children crossed out in a_systems; MapEntity, PerceptionManager and SCR_AIWorld are separate objects."
  caption="Removing the Game Master game mode."
  originalLabel="Open original image"
/>

Double-click `a_systems` to make it the active layer. In **Resource Browser**, select the **LiteLobby** project and enter `GameMode` in the search box. Find `LL_GameMode_Lobby.et`.

An `.et` file is a **prefab**, a ready-made object template with its settings. Drag `LL_GameMode_Lobby.et` from **Resource Browser** onto the map in the editor viewport. The Lite Lobby game mode and its child system objects will appear in `a_systems`.

<LL_Screenshot
  src={lobbyGameMode}
  alt="LL_GameMode_Lobby.et found in Resource Browser, with LL_GameMode_Lobby1 and its children added to a_systems."
  caption="The Lite Lobby game mode added to the mission."
  originalLabel="Open original image"
/>

Press `Ctrl+S` to save the world.

## Mission name and description {#mission-details}

In your addon's **Resource Browser**, open `Missions/ShootingStar_Ep1.conf`, created by the [setup wizard](/lite-lobby-ar/create-mission/world/#create-mission-header), and enter your mission's details:

| Field | What to enter |
| --- | --- |
| **World** | Your mission's world file. The wizard has already set this to `ShootingStar_Ep1.ent`. |
| **Name** | The mission name players will see in the scenario list. |
| **Author** | Your name or nickname. |
| **Description** | A short description of who takes part in the mission and where it takes place. |
| **Player Count** | How many players the mission is designed for. The example uses `128`. |

Under **Save Types**, clear all four checkboxes: **MANUAL**, **AUTO**, **SCRIPTED**, and **SHUTDOWN**. These control progress saves during gameplay.

<LL_Screenshot
  src={missionDetails}
  alt="ShootingStar_Ep1.conf with World, Name, Author, Description and Player Count filled in, and all Save Types disabled."
  caption="Mission name, description, and settings."
  originalLabel="Open original image"
/>

Press `Ctrl+S` to save the scenario file.

## Configure the map {#map-setup}

`MapEntity` controls the map players open during the mission. We will assign Everon's existing map files.

Return to **World Editor**. In **Hierarchy**, select `MapEntity` in `a_systems`. **Object Properties** on the right should list `SCR_CompassComponent` and `SCR_WristwatchComponent` — the compass and watch. These are usually already present. If either is missing, click **Add Component** at the bottom of the panel, search for its name, and select it from the list.

Click the top **SCR_MapEntity** row in **Object Properties** and expand **Unsorted**. Click `…` beside each of the two fields and select the file from the **ArmaReforger** project:

- **Map Geometry Data** — `worlds/Eden/Eden.topo`. This contains roads, buildings, and other objects displayed on the map.
- **Satellite background image** — `UI/Textures/Map/worlds/EveronRasterized.edds`. This provides the map background with terrain relief and forests.

<LL_Screenshot
  src={mapSetup}
  alt="MapEntity selected, with compass and watch components in Object Properties and Eden.topo and EveronRasterized.edds assigned to the map fields."
  caption="Everon map settings."
  originalLabel="Open original image"
/>

Press `Ctrl+S` to save the settings.
