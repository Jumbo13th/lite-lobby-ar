Use this section once your mission is complete to configure it for the Triad Tactics server. Also read the [mission requirements](../requirements/), including the rules for assigning objective points.

## 1. Add Triad Tactics Core {#core-dependency}

Add **[Triad Tactics Core](https://reforger.armaplatform.com/workshop/69FF2C2B633BBC25)** as a project dependency. **Project Settings → Dependencies** must list **Triad Tactics Core** with the identifier `69FF2C2B633BBC25`. This dependency is required for missions on the server.

Download the addon from Workshop and add it [the same way as Lite Lobby](../../create-mission/project/#lite-lobby-dependency). For rules on other gameplay mods, see the [mission requirements](../requirements/#gameplay-mods).

## 2. Trigger points {#trigger-points}

In **World Editor**, select the capture trigger — `PortCapture` in this example. In **Object Properties**, open **LL_TriggerZoneCapture** and set:

- **Stat Points** — the total point pool for the zone.
- **Stat Max Per Player** — the per-participant limit used when distributing points between units.

The screenshot shows `20` and `1`. Agree on values for your mission with the administrators, as specified in the [points requirements](../requirements/#points).

## 3. Statistics zone {#stat-zone}

Select the object that defines the capture zone boundary — `PortTrigger` in this example. Use **Add Component** to add **LL_StatZoneComponent** to it.

This component marks an area where enemy kills earn extra points. The victim must be inside the zone; the shooter's position does not determine the bonus. The point multiplier is configured on the server.

## 4. Session saves {#session-saves}

The server saves the game regularly. If the server crashes, the game continues from the last save.

Triad Tactics Core ticks **Session Saves** in the game mode for you. To check, select `LL_GameMode_Lobby1` in **Hierarchy** and type `sess` in the property search box in **Object Properties**.

<LL_Screenshot
  src={sessionSaves}
  alt="LL_GameMode_Lobby1 selected; the property search for sess shows Session Saves ticked under Lite Lobby."
  caption="Session Saves in the game mode."
  originalLabel="Open original image"
/>

The mission only has to allow saving. In **Resource Browser**, open `Missions/ShootingStar_Ep1.conf`.

Under **Save Types**, tick all four checkboxes again: **MANUAL**, **AUTO**, **SCRIPTED** and **SHUTDOWN**. With all four cleared, as in [the mission name and description step](../../create-mission/world/#mission-details), the game saves nothing.

<LL_Screenshot
  src={saveTypes}
  alt="ShootingStar_Ep1.conf with all four Save Types ticked: MANUAL, AUTO, SCRIPTED and SHUTDOWN."
  caption="All four save types ticked."
  originalLabel="Open original image"
/>

Click `..` next to **Systems Config**, open **LiteLobby → Configs → Systems** and choose `LL_LobbySystems.conf`.

<LL_Screenshot
  src={systemsConfig}
  alt="The Choose SystemsConfig dialog with LiteLobby/Configs/Systems/LL_LobbySystems.conf selected; Systems Config shows LL_LobbySystems.conf."
  caption="The lobby's systems config."
  originalLabel="Open original image"
/>

Press `Ctrl+S` to save the scenario file.

After a crash, the game finds each group by its object name. Give every group with playable slots [a name of its own](../../create-mission/groups-and-slots/#group-callsigns), such as `AB_S1`; no two groups may share a name.
