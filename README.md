# Lite Lobby

An Arma Reforger addon made by Triad Tactics for organized multiplayer missions, with slot selection, lobby voice chat (VoN), map briefings and mission objectives.

- [Workshop](https://reforger.armaplatform.com/workshop/699319AAA5BFC57F) — download the addon.
- [Mission-making guide](https://jumbo13th.github.io/lite-lobby-ar/) — create a mission from opening Arma Reforger Tools to publishing in Workshop.
- [Triad Shooting Star](https://github.com/Jumbo13th/triad-shooting-star-ar) — an example mission built with Lite Lobby.
- [Triad Tactics](https://triad-tactics.com/en) — our community and games.
- [Discord](https://discord.gg/t8TK9Y2vsM) — join our community.
